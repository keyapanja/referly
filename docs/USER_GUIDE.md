# User guides

The guides live with the product and render inside the app, one per audience:

| Audience | Source | In the app |
|---|---|---|
| Merchant, running a workspace | [apps/web/content/merchant-guide.md](../apps/web/content/merchant-guide.md) | Guide, in the merchant sidebar |
| Affiliate, in the partner portal | [apps/web/content/affiliate-guide.md](../apps/web/content/affiliate-guide.md) | Guide, in the portal sidebar |
| Platform admin | [apps/web/content/admin-guide.md](../apps/web/content/admin-guide.md) | Guide, in the admin sidebar |

Those markdown files are the single source: the pages read them at build time, so editing the file is all it takes to change what users read. Keep them in the reader's language (what they are trying to do), and leave operator and deployment detail to [DEPLOYMENT.md](DEPLOYMENT.md).
